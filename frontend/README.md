## 🧠 Philosophy

| 기준 | 일반 IDE | Baduck Coding |
|------|---------|---------------|
| 접근 | 코드 먼저 | **전략(아키텍처) 먼저** |
| 설계 | 자유 형식 | **바둑 포석처럼 체계적** |
| AI | 자동완성 | **구조적 조언** |

```mermaid
graph TD
    A[포석: 아키텍처 설계] --> B[중반: 모듈 구현]
    B --> C[끝내기: 리팩토링]
    C --> D[복기: 코드 리뷰]
```

## 🎯 Getting Started

```bash
git clone https://github.com/Reasonofmoon/baduck-coding.git
cd baduck-coding && npm install && npm run dev
```
